# Getting help with Secant

## Ask a question or report a bug

Open an issue on [secantdev/secant-releases](https://github.com/secantdev/secant-releases/issues). Search the existing issues first; someone may
already have asked.

## Report a security problem

Do not open a public issue. Report it privately through GitHub private vulnerability reporting:
[report a vulnerability](https://github.com/secantdev/secant-releases/security/advisories/new). Only the maintainers see the report.

## What is supported

Only the latest release is supported, on these platforms:

- Windows x64
- macOS arm64
- Linux x64

To move to the latest release, run the install command from the [README](./README.md) again. Fixes are not made to older releases or for other
platforms.

## What to include

- The output of `secant --version`.
- Your operating system and its version, for example Windows 11 or macOS 15.
- What you did, what you expected, and what happened instead.
